# De una base de Excel a un dashboard en Power BI

## Sobre el proyecto

Este repositorio documenta el proceso de desarrollo de un dashboard de análisis de ventas realizado en **Power BI**, utilizando como fuente de información una base de datos en **Excel**.

El proyecto tuvo como objetivo transformar los datos disponibles en información útil para el análisis, mediante la construcción de indicadores y visualizaciones relacionadas con ventas, costos, rentabilidad y unidades vendidas.

Durante el desarrollo surgieron diferentes desafíos relacionados con la preparación de los datos, el modelado, la creación de una tabla calendario, la construcción de medidas DAX y la adaptación de los requerimientos del proyecto a visualizaciones concretas.

Este repositorio también documenta los problemas encontrados, las acciones realizadas para resolverlos y los aprendizajes obtenidos mediante un enfoque de **post-mortem constructivo**.
